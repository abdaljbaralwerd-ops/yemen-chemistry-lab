# معمل الكيمياء اليمني التفاعلي

نسخة أولية من تطبيق تعليمي عربي يعمل كتطبيق ويب تقدمي (PWA)، ويمكن تثبيته من المتصفح بعد نشره على استضافة تدعم HTTPS.

## محتويات المشروع
- `index.html`: هيكل الواجهة.
- `css/style.css`: التصميم.
- `js/app.js`: الوحدات والتفاعل والاختبار.
- `manifest.webmanifest`: بيانات التثبيت.
- `service-worker.js`: تخزين ملفات التطبيق للعمل دون اتصال.
- `assets/icon.svg`: أيقونة التطبيق.

## النشر المجاني على GitHub Pages
1. أنشئ حسابًا في GitHub.
2. أنشئ مستودعًا جديدًا (Repository).
3. ارفع جميع ملفات ومجلدات المشروع مع الحفاظ على بنيتها.
4. افتح Settings ثم Pages.
5. اختر النشر من الفرع `main` والمجلد `/root` ثم Save.
6. انتظر رابط الموقع. افتحه عبر HTTPS مرة واحدة، ثم استخدم خيار التثبيت من المتصفح إذا ظهر.

يمكن استخدام استضافات ثابتة أخرى تدعم HTTPS مثل Cloudflare Pages أو Netlify.

## ملاحظات مهمة
- التخزين دون اتصال يبدأ بعد فتح الموقع بنجاح واتصال الإنترنت أول مرة حتى تُحفظ الملفات.
- أُضيفت Google Fonts كتحسين اختياري؛ عند عدم توفر الإنترنت يستخدم المتصفح خطوطًا محلية بديلة.
- المحتوى الموجود حاليًا تمهيدي عام، وليس تفريغًا موثقًا لكتاب الكيمياء المدرسي. يجب مراجعته ومطابقته مع الكتاب قبل اعتماده تعليميًا.
- المحاكاة في الوحدة الخامسة افتراضية وتوضيحية فقط. لا تتضمن خطوات عملية لتجربة كيميائية خطرة.
- حفظ تقدم الاختبارات محلي على الجهاز باستخدام LocalStorage.

## التحويل لاحقًا إلى APK
بعد اعتماد نسخة الويب، يمكن استخدام Capacitor لإضافة Android wrapper. ستحتاج بيئة تطوير Android المناسبة لبناء ملف APK. الاستضافة وحدها لا تنتج APK تلقائيًا.
